# bja-ltd.github.io

Public GitHub Pages site for BJA-LTD: privacy policies and support info for our games and apps.
Live at https://bja-ltd.github.io/ — published from the `main` branch root (site content only, no staging flow).

- `privacy/<game>.html`: one privacy policy per app, linked from the app's Google Play listing.
  The source copy for offline-games apps lives in `BJA-LTD/offline-games` under `docs/privacy/`; copy it here when it changes.
